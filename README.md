# 💻 CS & C++ Interactive Quiz & Exam Revision Platform
### منصة المراجعة التفاعلية لمادة مقدمة الحاسوب وبرمجة C++

منصة ويب تفاعلية حديثة وشاملة تم تصميمها خصيصاً لمراجعة واختبار مادة مقدمة الحاسوب والبرمجة بلغة C++، بمحاكاة دقيقة 100% لنفس نمط وصعوبة أسئلة الامتحانات والسلايدز.

---

## ✨ المميزات الرئيسية (Key Features)

- ⚡ **تصحيح فوري وتفاعلي**: يوضح ما إذا كانت الإجابة صحيحة (أخضر ✅) أو خاطئة (أحمر ❌) في اللحظة نفسها.
- 💡 **كشف الإجابة الصحيحة مع الشرح**: عند الخطأ، يتم تظليل الإجابة الصحيحة وإظهار كارت شرح تفصيلي يُبين القواعد والتعليلات.
- 🎯 **مراجعة الأخطاء فقط (Mistakes Only Mode)**: زر لفلترة الأسئلة والتركيز فقط على الأسئلة التي تم الخطأ فيها لإتقانها.
- 💀 **وضع أسئلة الدمار الفتاكة (Extreme Questions Mode)**: 50 سؤالاً تعجيزياً مصممة من أعتى ألغاز C++ ومصائد أنظمة العد مع أنيميشن ومؤثرات صوتية "دماااارررر" عند الدخول!
- ✍️ **أسئلة مقالية تفاعلية (Essay & Conceptual System)**: مساحة لكتابة مسودة الإجابة + كشف الإجابة النموذجية + قائمة تدقيق ذاتية (Rubric Checklist).
- 🔢 **محاكي أنظمة العد المباشر (Live Converter & 2's Complement)**: أداة تحويل فوري بين الأنظمة (Decimal, Binary, Octal, Hexadecimal) وحساب المكمل الثنائي.
- 📊 **لوحة متابعة وإحصائيات مباشرة**: عداد الإجابات، نسبة النجاح المئوية، شريط التقدم، وسلسلة الإجابات الصحيحة المتتالية (Streak 🔥).
- 🔊 **مؤثرات صوتية تفاعلية**: أصوات إيجابية وتنبيهية عبر Web Audio API بدون أي ملفات خارجية.
- 🌓 **دعم الوضع الليلي والفاتح (Dark / Light Mode)**.

## 📑 أقسام بنك الأسئلة (Question Bank)

1. **🔘 صح أو خطأ (True / False)**: أكثر من 27 سؤالاً يغطي المفاهيم النظرية، الذاكرة (RAM/Cache)، الـ Overflow، لغات البرمجة والـ CPU.
2. **📝 اختيار من متعدد (MCQ)**: أسئلة عن وحدات التخزين، أنواع الأخطاء (Syntax/Logic)، والنواقل (Control bus).
3. **💻 تتبع كود C++ والناتج (Code Tracing)**: تتبع المعاملات البعدية والقبلية (`r = x + y++;`)، جمل الـ switch، وحلقات التكرار.
4. **🛠️ اكتشاف الأخطاء وتصحيحها (Identify & Fix Errors)**: أخطاء حقيقية من ورقة الامتحان مثل: `cout >> count >> '/n'` و `int double = 44;`.
5. **🔢 أنظمة العد والمكملات (Number Systems & 2's Complement)**:
   - حل جدول الامتحان الكامل بطريقة Double Dabble ($143.75_{10}$، $11011.101_2$، $453_8$، $1F.C_{16}$).
   - مسألة الطرح بالمكمل الثنائي: $(-13)_{10} - (6)_{10} = (-19)_{10}$ بالخطوات وتمثيل 8-bit.
   - جدول السلايد لحساب $-22$ و $-123$ بنظم Signed Magnitude و 1's Comp و 2's Comp.
6. **📊 الخوارزميات وخرائط التدفق (Flowcharts & Algorithms)**:
   - تحويل درجات الحرارة من مئوية لفهرنهايت ($F = C \times 9/5 + 32$).
   - فحص الأعداد الموجبة والسالبة.
   - حساب مجموع مربعات الأعداد من 1 إلى 50 ($Sum = Sum + i^2$).
7. **✍️ أسئلة مقالية وشرح (Essay Questions)**:
   - أسباب تفضيل المكمل الثنائي (Two's complement) وإلغاء مشكلة الصفر المزدوج.
   - شرح ظاهرة الفيض الحسابي (Overflow) وشروط حدوثها وطريقة كشف المعالج لها.
   - شرح طريقة Double Dabble للكسور والأعداد الصحيحة.
   - أهمية واستخدامات النظام الست عشري (Hexadecimal).
   - خصائص الخوارزميات الخمس ووظائف الأشكال القياسية لخرائط التدفق.
   - خوارزميات ومخططات لإيجاد أكبر رقم بين 3 أرقام ومضروب العدد ($N!$).

## 🚀 تشغيل المشروع محلياً (Local Run)

المشروع مبني بـ Pure HTML5, CSS3, JavaScript (Vanilla JS) بدون أي حزم خارجية أو تبعيات معقدة:

### الخيار 1: فتح الملف مباشرة
فقط قم بالنقر المزدوج على ملف `index.html` وسيفتح مباشرة في متصفحك.

### الخيار 2: عبر السيرفر المحلي المرفق (Node.js)
```bash
node server.js
```
ثم افتح: [http://localhost:8080/](http://localhost:8080/)

## 🌐 النشر على GitHub Pages

يمكنك تشغيل هذا الموقع مباشرة كصفحة ويب مجانية من خلال تفعيل **GitHub Pages**:
1. اذهب إلى إعدادات المستودع (Settings).
2. اختر **Pages** من القائمة الجانبية.
3. تحت **Branch**، اختر `main` واضغط **Save**.
4. سيظهر لك رابط الموقع المباشر في غضون ثوانٍ.
